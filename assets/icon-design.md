## Generation prompt

Use case: logo-brand. Create an original production-ready macOS application icon for token-menu, a lightweight AI usage monitor in the menu bar. Single square 1024x1024 PNG with genuinely transparent exterior. A centered macOS rounded-square tile occupying about 84 percent of the canvas, midnight graphite enamel with subtle dimensional edge and restrained shadow; inside is one bold white circular usage gauge, about three-quarters full, with a small mint green terminal segment and a simple white horizontal menu-bar pill below its center. Elegant minimal native macOS utility design, crisp large silhouette legible at 16 and 32 pixels, polished but not glossy, restrained depth, perfectly symmetrical composition. No text, letters, numbers, percentage symbol, provider logos, watermark, surrounding mockup or extra objects. The resulting PNG will be used directly as the app icon and converted to ICNS.
