# Token Menu 1.0.8

This patch release prevents macOS security warnings caused by blocked Codex CLI binaries.

- Prefers the Codex executable bundled with the official ChatGPT/Codex app.
- Skips Codex executables carrying a quarantine attribute or an AppTranslocation path.
- Shows a clear refresh message when every detected Codex executable is blocked by macOS.
- Keeps standalone CLI fallback support when the executable is not quarantined.
- Preserves live usage refresh, task activity tracking, Claude Code support, menu-bar behavior, and launch-at-login.

The DMG is ad-hoc signed and is not Apple-notarized. Install `Token Menu.app` in `/Applications` before launching it so macOS does not run it from an AppTranslocation path.
