# Token Menu 1.0.9

This patch release improves active Codex task tracking and keeps completed task durations stable.

- Adds per-project up/down ordering controls for active AI tasks in Settings.
- Applies the saved task order to the menu-bar usage window and appends newly discovered tasks afterward.
- Stops completed task elapsed timers at the recorded completion time.
- Preserves live Codex usage refresh, Claude Code support, menu-bar behavior, notifications, and launch-at-login.

The DMG is ad-hoc signed and is not Apple-notarized. Install `Token Menu.app` in `/Applications` before launching it so macOS does not run it from an AppTranslocation path.
