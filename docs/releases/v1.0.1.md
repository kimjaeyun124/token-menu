# Token Menu 1.0.1

This patch release fixes percentage rendering across the menu bar, usage popover, settings preview, and notifications.

- Integer mode consistently shows values such as `0%`, `68%`, and `100%`.
- One Decimal mode always shows one digit, such as `0.0%`, `68.0%`, and `51.3%`.
- Rounding is deterministic and values outside 0–100, NaN, infinity, and missing values remain unavailable.
- Both-provider menu-bar output uses the same formatter for each provider.

The release also retains the Token Menu menu-bar behavior, Korean/English layouts, provider artwork, and launch-at-login support from 1.0.0.

The attached build is ad-hoc signed and is not Apple-notarized.
