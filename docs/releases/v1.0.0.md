# Token Menu 1.0.0

Token Menu is a native macOS menu bar utility for checking supported AI coding-service usage without keeping an icon in the Dock.

## Highlights

- Live Codex 5-hour and weekly remaining allowances in the menu bar and usage panel.
- Korean and English interfaces with localized reset countdowns, including days.
- Supplied Codex and Claude provider images with configurable white, black, accent, or secondary tint.
- Launch at login, manual refresh, notifications, an optional keyboard shortcut, and a settings window that follows the active desktop.
- Larger full-row settings sidebar targets and a protected minimum settings-window size.
- Universal Apple Silicon and Intel application bundle distributed as a DMG.

Claude Code usage can be connected through the documented status-line bridge included with the app. The bridge reads only the JSON payload Claude Code supplies to a status-line command; API-key and unsupported plans correctly remain unavailable.

The attached build is ad-hoc signed and is not Apple-notarized. See the README for first-launch guidance and verification limitations.
