# Token Menu 1.0.3

This patch release improves Codex activity visibility for the desktop Codex client.

- Detects active desktop Codex turns through local session lifecycle markers when the client uses a separate stdio app-server.
- Keeps the app-server activity connection read-only and does not surface prompt or tool contents.
- Preserves Codex and Claude usage refresh, whole-number percentages, reset countdowns, provider icons, menu-bar behavior, and launch-at-login support.
- Includes the universal Apple Silicon and Intel application bundle in the DMG.

The DMG is ad-hoc signed and is not Apple-notarized. Install `Token Menu.app` in `/Applications` before launching it so macOS does not run it from an AppTranslocation path.
