# Token Menu 1.0.11

This patch release improves AI activity detection when Codex is launched through a desktop app or another local runtime.

- Discovers additional running Codex app-server sockets even when the default server responds successfully without active tasks.
- Refreshes discovered runtime paths every 30 seconds while keeping the activity scan lightweight.
- Combines activity results from the primary and additional Codex runtimes.
- Preserves the existing menu-bar formats, provider colors, Claude Code detection, usage refresh, and notifications.

The DMG is ad-hoc signed and is not Apple-notarized. Install `Token Menu.app` in `/Applications` before launching it so macOS does not run it from an AppTranslocation path.
