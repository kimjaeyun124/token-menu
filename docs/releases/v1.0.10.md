# Token Menu 1.0.10

This patch release improves cross-environment AI activity detection and adds more flexible menu-bar presentation options.

- Detects active Codex tasks across supported local execution environments and running session layouts.
- Reduces menu-bar lag by avoiding unnecessary activity scans and repeated unchanged updates.
- Prevents Claude Code sessions from being incorrectly reported as completed Codex tasks.
- Adds provider icon-only display and configurable provider icon/text colors for light and dark menu bars.
- Adds an `Icon | 28%` menu-bar format that shows the selected usage percentage without `5H` or `Weekly` labels.
- Preserves live Codex usage refresh, Claude Code support, notifications, and launch-at-login.

The DMG is ad-hoc signed and is not Apple-notarized. Install `Token Menu.app` in `/Applications` before launching it so macOS does not run it from an AppTranslocation path.
