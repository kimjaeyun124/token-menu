# Token Menu 1.0.7

This release expands the AI activity panel and improves task state tracking.

- Separates currently used AI services from Codex usage details.
- Detects active Claude Code sessions from the local process list.
- Lists multiple Codex tasks with project names, elapsed time, and current state.
- Keeps completed tasks available until the user acknowledges them from Codex.
- Opens the corresponding ChatGPT Codex task when an activity row is selected.
- Sends a localized notification when a Codex task completes, when notifications are enabled.
- Preserves usage refresh, menu-bar behavior, provider icons, reset countdowns, and launch-at-login support.

The DMG is ad-hoc signed and is not Apple-notarized. Install `Token Menu.app` in `/Applications` before launching it so macOS does not run it from an AppTranslocation path.
