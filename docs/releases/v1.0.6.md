# Token Menu 1.0.6

This patch release improves active Codex task naming.

- Shows the project's display name (for example, `Token Menu`) when the session workspace contains bundle metadata.
- Falls back to the workspace folder name for projects without bundle metadata.
- Keeps every active task listed separately with its state and elapsed time.
- Does not read or display prompt and tool contents.

The DMG is ad-hoc signed and is not Apple-notarized. Install `Token Menu.app` in `/Applications` before launching it so macOS does not run it from an AppTranslocation path.
