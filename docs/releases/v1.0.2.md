# Token Menu 1.0.2

- Adds live Claude Code usage through the documented status-line `rate_limits` bridge.
- Includes the bridge script in the application bundle at `Contents/Resources/claude-statusline-token-menu.sh`.
- Shows Claude 5-hour and 7-day remaining percentages and reset times without reading credentials.
- Keeps the existing Codex menu-bar monitor, Korean/English UI, provider icons, and refresh behavior.

The DMG is ad-hoc signed and is not Apple-notarized. See the README for Claude Code status-line setup.
