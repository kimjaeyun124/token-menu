# Token Menu 1.0.4

This patch release fixes delayed Codex activity recognition after launch.

- Prioritizes recently modified Codex session files instead of rescanning the entire session history.
- Parses only lifecycle markers needed to show the active task and elapsed time.
- Keeps prompt and tool contents out of the activity snapshot and UI.
- Preserves usage refresh, menu-bar behavior, provider icons, reset countdowns, and launch-at-login support.

The DMG is ad-hoc signed and is not Apple-notarized. Install `Token Menu.app` in `/Applications` before launching it so macOS does not run it from an AppTranslocation path.
