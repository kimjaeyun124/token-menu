# Token Menu 1.0.5

This patch release improves the Codex activity panel.

- Lists every active Codex task instead of showing only the first task.
- Labels each task separately and shows its workspace name when available.
- Keeps per-task state and elapsed time visible while preserving usage refresh and menu-bar behavior.
- Does not read or display prompt and tool contents from local session records.

The DMG is ad-hoc signed and is not Apple-notarized. Install `Token Menu.app` in `/Applications` before launching it so macOS does not run it from an AppTranslocation path.
